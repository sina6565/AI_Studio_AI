# App Workspace

این پوشه محل نگه‌داری ساختار تفکیک‌شدهٔ اپلیکیشن‌هاست. وجود یک پوشه در این مسیر به‌تنهایی به معنی مستقل، قابل اجرا یا آمادهٔ انتشار بودن آن اپلیکیشن نیست.

## مسیرهای موجود

- `apps/product-web/` — پوشهٔ مستندات Product Web
- `apps/cinematic-site/` — پوشهٔ مستندات تجربهٔ سینمایی
- `apps/mobile-product/` — پوشهٔ مستندات Mobile Product
- `apps/mobile-brand/` — پوشهٔ مستندات Mobile Brand

## وضعیت فعلی

در وضعیت فعلی این چهار مسیر دارای فایل معرفی هستند؛ برای آن‌ها `package.json` مستقل در این شاخه تأیید نشده است. بنابراین نباید آن‌ها را اپلیکیشن‌های مستقل و آمادهٔ اجرا یا انتشار معرفی کرد.

کدهای اجرایی شناخته‌شدهٔ پروژه همچنان در مسیرهای ریشهٔ مخزن قرار دارند:

- `frontend/` — فرانت‌اند وب
- `backend/` — بک‌اند
- `mobile/` — اپلیکیشن موبایل

## قاعدهٔ توسعه

انتقال هر بخش به این workspace فقط پس از بررسی وابستگی‌ها، entry pointها، تنظیمات build/test، مسیرهای CI و سازگاری runtime انجام می‌شود. تا پیش از تکمیل و اعتبارسنجی انتقال، مسیرهای فعلی ریشه مرجع اجرایی باقی می‌مانند.
