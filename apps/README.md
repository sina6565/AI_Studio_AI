# App Structure

این پوشه برای ساختار جدید مخزن در نظر گرفته شده است.

## ساختار هدف
- `apps/product-web/` → اپ اصلی وب محصول
- `apps/cinematic-site/` → landing و تجربهٔ سینمایی
- `apps/mobile-product/` → اپ موبایل محصول
- `apps/mobile-brand/` → تجربهٔ سینمایی موبایل
- `packages/` → shared code

## وضعیت فعلی
در حال انتقال از ساختار کوتاه‌مدت به ساختار توسعه‌ای و publish-ready است.
