# Mobile Brand

صفحهٔ خوش‌آمدگویی و معرفی برند در اپلیکیشن موبایل فعلی قرار دارد.

- صفحهٔ خوش‌آمدگویی: `mobile/src/screens/WelcomeScreen.tsx`
- نقطهٔ ورود و Navigation: `mobile/src/App.tsx`
- منابع زبان و ترجمه: بخش‌های مربوط در `mobile/src/`

در `apps/mobile-brand/` فقط فایل معرفی وجود دارد؛ این مسیر package یا اپلیکیشن مستقل قابل اجرا ندارد.
