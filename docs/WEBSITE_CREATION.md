# Website Builder

The authenticated \`website_build\` job creates a responsive, editable, standalone HTML site using the local SINA template engine. It does not require an external AI provider, paid API, or Redis specifically; it uses the existing job queue and MongoDB lifecycle. In \`QUEUE_MODE=auto\` or \`inline\`, it can run without Redis.

## Supported inputs

\`name\`, \`tagline\`, \`description\`, \`kind\` (\`portfolio\`, \`business\`, or \`product\`), \`palette\` (\`midnight\`, \`light\`, or \`ocean\`), \`language\` (\`en\` or \`fa\`), and an optional validated \`contactEmail\`.

## Output

The optional `features` array supports up to six user-defined sections, each with an escaped title and description. The standalone document includes a descriptive title, meta description, robots directive, Open Graph/Twitter metadata, and a small Schema.org `WebSite` JSON-LD block. No canonical URL is emitted because the builder does not know the eventual public domain.

A completed job includes a downloadable \`text/html\` data URL and \`result.metadata.html\`, \`filename\`, and generator metadata. The builder supports an in-app sandboxed preview, source editing, and HTML download. The HTML has no external script or runtime dependency.

## Deliberate limits

The fallback is a deterministic local prompt interpreter and template/code generator, not an LLM. When Ollama is configured, the content specification is generated by the local model; the output is still constrained by a strict schema and safely escaped HTML renderer. The output is a single-page HTML draft, not a complete e-commerce backend or arbitrary React/Vue project. Multi-page routing, persistent revision history, automated content generation, hosted publishing, DNS and production hosting are not implemented yet. The current output can be previewed, source-edited and downloaded for manual deployment.


## Optional local text model

Set `OLLAMA_ENABLED=true`, `OLLAMA_BASE_URL` and `OLLAMA_MODEL` on the backend. The default model name is `qwen2.5:7b`; it must already be installed in the self-hosted Ollama instance. The app does not download models automatically. Use HTTPS for public remote endpoints; HTTP is permitted for loopback, private IPv4, and explicitly local/private hostnames such as a self-hosted Docker service. If the endpoint or model is unavailable, prompt builds continue through the deterministic local fallback.
