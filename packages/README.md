# Shared Packages

این پوشه برای سازمان‌دهی کدهای مشترک میان اپلیکیشن‌های SINA AI STUDIO در نظر گرفته شده است.

## حوزه‌های پیشنهادی

- `shared-ui` — اجزای رابط کاربری مشترک
- `shared-api` — قراردادها و لایهٔ ارتباط با API
- `shared-i18n` — منابع و ابزارهای چندزبانه
- `shared-types` — typeها و قراردادهای مشترک
- `design-system` — توکن‌ها و الگوهای طراحی

## وضعیت فعلی

موارد بالا حوزه‌های معماری پیشنهادی‌اند، نه تأیید وجود packageهای مستقل. در این شاخه برای این نام‌ها `package.json` مستقل تأیید نشده است؛ بنابراین نباید آن‌ها را packageهای آمادهٔ import یا build معرفی کرد.

کدهای مشترک موجود باید پیش از انتقال، از مسیرهای فعلی شناسایی و وابستگی‌هایشان بررسی شوند. ایجاد package مستقل مستلزم تعریف ورودی/خروجی، وابستگی‌ها، اسکریپت‌های build و test و اتصال معتبر به workspace است.

## قاعدهٔ انتقال

تا زمان انتقال و اعتبارسنجی، هیچ import، build یا runtime نباید به packageهای صرفاً پیشنهادی وابسته شود.
